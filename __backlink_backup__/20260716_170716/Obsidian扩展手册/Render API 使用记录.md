# Render API 使用记录

## 这是什么

`Render API` 的核心作用是“返回渲染后的结果”。普通读取只会拿到 Markdown 原文，而 Render API 更适合把 Dataview、Markdown、Tasks 这类内容渲染后再交给外部程序使用。

当前安装版本：`0.2.5`

## 它能为你带来的具体功能

- 获取某篇笔记渲染后的内容
- 获取 Dataview 查询渲染结果
- 更适合给 AI、网页、自动化工具直接消费
- 可以减少外部程序自己解析 Obsidian 内容的负担

## 最适合你的场景

- 想做自己的知识面板
- 想让 AI 读取“最终展示结果”
- 想把 Obsidian 的查询页输出给别的系统

## 推荐配置教程

1. 打开 `设置 -> 社区插件 -> Render API`
2. 先确认它和 Local REST API 的角色不同
3. 看插件文档里的端点说明
4. 先从最简单的单篇笔记渲染开始测试

## 推荐理解方式

- `Local REST API` 更像“原始数据接口”
- `Render API` 更像“渲染结果接口”

## 典型使用例子

- 把 Dataview 总览页输出给网页
- 把任务页渲染结果提供给脚本
- 把某个知识页的最终内容提供给 AI

## 注意事项

- 如果你只是自己在 Obsidian 内使用，短期内不一定会高频用到它
- 但如果你以后要做 AI、自动化、外部看板，它会非常重要
- 和接口类插件一样，注意本地接口安全
