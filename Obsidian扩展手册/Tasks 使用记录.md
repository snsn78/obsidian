# Tasks 使用记录

## 这是什么

`Tasks` 是 Obsidian 生态里最成熟的任务插件之一。它扩展了 Markdown 任务语法，让你可以添加截止日期、计划日期、周期任务、优先级，并且能统一查询。

当前安装版本：`8.2.2`

## 它能为你带来的具体功能

- 统一管理所有待办事项
- 给任务加截止日期、开始日期、完成日期
- 支持周期任务
- 按项目、目录、标签、日期筛选任务
- 做今日任务、项目任务、逾期任务面板

## 最适合你的场景

- 学习计划
- 项目推进
- 每日待办
- 复习提醒

## 推荐配置教程

1. 打开 `设置 -> 社区插件 -> Tasks`
2. 先看一遍日期格式相关设置
3. 如果你想统一视觉效果，可以开启全局任务显示选项
4. 建议先保持其他设置默认

## 基础写法

```markdown
- [ ] 完成 Beckoff 学习记录
- [ ] 整理控制理论错题 📅 2026-07-18
- [ ] 写周总结 🔁 every week on Sunday
```

## 常用查询示例

显示所有未完成任务：

```tasks
not done
sort by due
```

显示今天到期的任务：

```tasks
not done
due today
```

显示某个目录下的任务：

```tasks
not done
path includes 数学
```

## 推荐你建立的页面

- 今日任务页
- 本周任务页
- 项目任务页
- 逾期任务页

## 和其他插件的联动方式

- 配合 `Dataview`：在总览页里同时展示任务与笔记
- 配合 `QuickAdd`：新建笔记时预置任务区
- 配合 `Templater`：自动生成每日待办结构

## 注意事项

- Tasks 很适合“放在笔记里管理任务”，不适合替代大型团队项目软件
- 如果你以后要做任务体系，建议先统一任务写法，再做查询页
