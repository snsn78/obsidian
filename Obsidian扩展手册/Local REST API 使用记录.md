# Local REST API 使用记录

## 这是什么

`Local REST API with MCP` 会把你的 Obsidian 库暴露成本地接口。这样脚本、自动化工具、AI 代理就可以读取笔记、写入笔记、搜索内容，甚至把 Obsidian 当成本地知识库后端。

当前安装版本：`4.1.7`

## 它能为你带来的具体功能

- 让外部脚本读取你的笔记
- 让自动化程序写入新笔记或更新旧笔记
- 让 AI 工具以接口形式访问你的知识库
- 为以后做“知识库助手”“自动整理系统”打基础

## 最适合你的场景

- 想把 Obsidian 接到 Codex、脚本、Agent、自动化流程里
- 想自动生成笔记、同步内容、做批处理

## 推荐配置教程

1. 打开 `设置 -> 社区插件 -> Local REST API`
2. 阅读插件里的安全提示
3. 查看监听端口
4. 查看认证方式或 API Key 设置
5. 只在你明确知道用途时，再把它接到外部工具

## 典型使用方式

- 搜索某个关键词对应的笔记
- 自动向某个目录写入日志
- 从外部程序触发知识记录
- 让 AI 根据你的笔记上下文回答问题

## 安全注意事项

- 这是接口类插件，和普通样式插件不一样
- 它涉及“外部程序访问本地知识库”的能力
- 建议只在本机使用，不要随便映射到公网
- 如果插件提供认证口令或 API Key，务必保管好

## 和其他插件的联动方式

- 配合 `Render API`：一个负责拿原始内容，一个负责拿渲染结果
- 配合 `Templater` / `QuickAdd`：外部程序也能按统一结构写入笔记

## 什么时候你会明显用到它

当你不满足于“手工打开 Obsidian 记笔记”，而是想让别的程序也参与知识管理时，这个插件价值会非常高。
