# Advanced Tables 使用记录

## 这是什么

`Advanced Tables` 是 Markdown 表格增强插件。它的价值很直接：让你在 Obsidian 里写表格不再痛苦。

当前安装版本：`0.23.2`

## 它能为你带来的具体功能

- 自动对齐表格列
- 更方便地新增行、列
- 输入时自动保持表格格式整齐
- 大幅降低 Markdown 表格编辑成本

## 最适合你的场景

- 做学习资料整理表
- 做项目清单表
- 做参数对比表
- 做课程计划表

## 推荐配置教程

1. 打开 `设置 -> 社区插件 -> Advanced Tables`
2. 基本保持默认即可
3. 重点是熟悉它的编辑行为和快捷方式

## 最明显的使用收益

你以后在表格中按 `Tab`、回车或修改列内容时，会明显感觉比原生 Markdown 表格更顺。

## 一个最简单例子

```markdown
| 名称 | 状态 | 备注 |
| --- | --- | --- |
| 数学 | 进行中 | 继续补充 |
| BECKOFF | 已开始 | 整理资料 |
```

## 日常使用建议

- 把它当成“无脑常驻插件”
- 凡是需要对比、清单、参数整理时都优先用表格

## 注意事项

- 它主要提升编辑体验，不负责数据库查询
- 如果你想做动态表格汇总，还是要配合 `Dataview`
