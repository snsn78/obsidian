可以，我们先做**最稳的一版：手机开热点，K230 连手机热点，手机用 VLC 看 K230 的 RTSP 图传**。

我查的 Yahboom 本地文件是：

```
程序源码\11.Network\07.rtsp\rtsp_no_ai.py
程序源码\11.Network\01.wifi\connetc_wifi.py
程序源码\11.Network\02.hotspot\ap.py
```

**第一步：手机准备**

1. 手机安装 `VLC` 播放器。
2. 打开手机热点。
3. 热点设置成：
    - 频段：`2.4GHz`
    - 名称：尽量英文，比如 `K230TEST`
    - 密码：比如 `12345678`
4. 不要用中文热点名，先别用 5GHz。

**第二步：电脑连接 K230**

1. K230 插好摄像头、屏幕、TF 卡。
2. 用 USB 连接电脑。
3. 打开 `CanMV IDE for K230`。
4. 连接开发板。
5. 打开这个文件：

```
E:\学行班\硬件学习\电赛准备\k230\YAHBOOM_资料\K230视觉模块\程序源码\11.Network\07.rtsp\rtsp_no_ai.py
```

**第三步：改 WiFi 名和密码**

在文件最后找到这一行：

```
isConnected = Connect_WIFI("test", "123456")
```

改成你手机热点的信息，例如：

```
isConnected = Connect_WIFI("K230TEST", "12345678")
```

先只改这一处就够了。

**第四步：运行 K230 程序**

在 CanMV IDE 里点击运行。控制台正常应该出现类似：

```
[WIFI] 连接网络中 Connecting to network ...
192.168.xx.xx
[WIFI] 网络连接成功 Network connection successful
[RTSP] Starting ...
[RTSP] Started successfully, address: rtsp://192.168.xx.xx:8554/video
```

最后这句就是你手机要打开的地址。

**第五步：手机看图传**

1. 手机打开 VLC。
2. 找到“网络串流”或“打开网络串流”。
3. 输入 K230 打印出来的地址：

```
rtsp://192.168.xx.xx:8554/video
```

4. 点播放。

看到摄像头实时画面，就成功了。

**第六步：录像保存**

题目要求“显示、记录、回放”，手机上最简单：

```
手机 VLC 看画面
+
手机系统自带录屏
```

测试前开始录屏，测试后停止，就能保存和回放。

**如果打不开，按这个顺序排查**

1. 确认手机热点是 `2.4GHz`。
2. 确认 K230 控制台打印的不是 `0.0.0.0`。
3. 确认 VLC 地址完整：

```
rtsp://K230的IP:8554/video
```

4. K230 和手机要在同一个网络里。
5. 有些手机热点会隔离设备，导致“手机自己开热点，却访问不了连进来的 K230”。如果这样，换方案：
    - 用另一台手机 A 开热点；
    - K230 连手机 A；
    - 你的手机 B 也连手机 A；
    - 手机 B 用 VLC 打开 RTSP 地址。

备用方案是让 K230 自己开热点、手机连 K230，但 Yahboom 的 `ap.py` 只是 AP 示例，还要和 `rtsp_no_ai.py` 合并，第一版不建议先走这条。

你现在照着做的最短路径就是：

```
手机开 2.4G 热点
改 rtsp_no_ai.py 里的 SSID/密码
CanMV IDE 运行
手机 VLC 打开 rtsp://...:8554/video
手机录屏保存
```

先把这个跑通，后面再把钢球识别画框叠加进 RTSP 图传。
