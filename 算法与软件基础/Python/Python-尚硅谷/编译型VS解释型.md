# 编译型
1.在windows上的可执行程序叫做exe，如果在其他电脑上就是其他的执行
2.如果在其他电脑上运行，只要分享这个exe文件就行（这个很好理解，下载的安装包就是这样的）
3.但是只是这个.exe还不够，必须保证所要执行的电脑上有相同的系统架构（[[什么叫做系统架构？]]）
4.同一运行平台只需要运行一次，执行编译只需要使用一次，执行效率高，但是跨平台性差，大型项目编译时间长，开发效率比较低

# 解释型语言
1.跨平台性好，无需编译，开发调试比较灵活
2.每次运行都需要重新解释，执行效率低
